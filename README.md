# 📘 Khatabook - Digital Ledger Web App

A simple and user-friendly digital ledger (hisaab) management website where users can create, update, and delete transaction entries easily. Built using **Node.js**, **Express.js**, and **Tailwind CSS**, this app helps you keep track of personal or business records in a smooth and organized manner.

## ✨ Key Features

- 📥 Add and manage your hisaab entries with ease
- ✏️ Edit transaction records using the edit button
- ❌ Delete unwanted entries with a single click
- 📱 Clean and responsive UI powered by Tailwind CSS
- 🔐 Structured backend using Node.js and Express.js for efficient data flow
- 💾 Data persistence with modular and maintainable code
